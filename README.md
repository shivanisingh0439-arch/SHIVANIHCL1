# Airline Operations & Performance Analysis

## Project structure
- `notebooks/airline_data_analysis.ipynb` — analysis notebook
- `data/raw/airlines_data.csv` — original input data
- `data/processed/airlines_data_clean.csv` — cleaned and feature-engineered data
- `images/` — charts generated by the notebook

## Run
Open the notebook in Jupyter Notebook or JupyterLab. The notebook expects the project folder structure to remain unchanged. Install dependencies with:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

Run all cells from top to bottom.
